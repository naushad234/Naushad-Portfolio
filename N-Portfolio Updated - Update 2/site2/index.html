Hospital Management System

A multi-role hospital management platform handling patient-care operations end to end — built with Flask and MySQL.

Technical Implementation
  • Flask backend with session-based authentication and role-based access control (Admin vs. Patient), enforced through route-protecting decorators
  • 10 relational MySQL tables — patients, doctors, appointments, medical records, departments, room allotments, vaccination records, doctor schedules, chatbot Q&A, admins — via mysql-connector-python
  • Full CRUD routes for every module, server-rendered with Flask/Jinja templates
  • Patients restricted to read-only access; admins get full add/update/delete permissions via a custom decorator
  • Rule-based chatbot backed by its own database table for common patient FAQs

HIGH-VALUE PROJECT
02
React Web Application • API Integration

SkyCast — Weather Dashboard

A React weather dashboard built on the OpenWeatherMap API, with real data visualization and persisted preferences.

Technical Implementation
  • Built with React and a Context API store (WeatherContext) as the single source of truth for location, units, weather data and favorites
  • Dedicated API layer wrapping OpenWeatherMap's One Call 3.0, Geocoding and Air Pollution endpoints, with typed error handling for rate limits, bad keys and not-found locations
  • Custom hooks: useGeolocation (auto-detects location on load), useDebounce (350ms debounced search), useLocalStorage (persists units/favorites/settings)
  • Interactive radar map via react-leaflet with switchable precipitation/cloud/temperature tile overlays
  • Precipitation charting with Chart.js; falls back to the free current-weather endpoint if One Call 3.0 isn't enabled on the API key
Tech Stack
ReactJavaScriptOpenWeatherMap APIReact LeafletChart.jsContext API
Key Features
  • Auto-geolocation + debounced city search with autocomplete
  • Hourly & 7-day forecast, air quality index, sunrise/sunset
  • Interactive radar map with multiple weather layers
  • Saved locations & settings persisted in localStorage
